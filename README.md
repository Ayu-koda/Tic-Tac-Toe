## ✨ Features

- 👥 **Two-player mode**: play against a friend on the same device
- 🔄 **Live turn indicator**: always shows whose turn it is
- 🏆 **Automatic win detection**: checks all 8 winning combinations (rows, columns and diagonals)
- 🟣 **Animated winning line**: a purple line is drawn across the three winning boxes
- 🐱 **Celebration animation**: a cheerful cat appears when someone wins
- 🔊 **Sound effects**: a tick sound on every move, plus game-over audio
- 🔁 **Reset button**: start a fresh game instantly
- 📱 **Responsive design**: layout adapts to smaller screens

## 🚀 Getting Started

No installation or build step is needed.

1. **Clone the repository**
   ```bash
   git clone https://github.com/Ayu-koda/Tic-Tac-Toe.git
   ```
2. **Go into the project folder**
   ```bash
   cd Tic-Tac-Toe
   ```
3. **Open the game**: double-click `index.html`, or run it with the **Live Server** extension in VS Code.

---

## 🎮 How to Play

1. **X** always goes first.
2. Click any empty box to place your mark.
3. Players take turns until one of them gets **three in a row** (horizontal, vertical or diagonal).
4. The winner is announced and a line is drawn through the winning boxes.
5. Press **Reset** to play again.
